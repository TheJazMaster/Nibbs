# Nibbs, the Interdimensional Warrior
A Cobalt Core mod that adds Nibbs from the videogame **Awesomenauts** as a homage to the fallen-from-grace game. More characters are planned "soon".

Nibbs can act as the ship's **pilot** with a lot of **backtrackable instant movement**, **stunning** attacks, temporary **flippability** and other transient statuses, and uses **time stop** to help keep them.

![Sprite of the character](https://github.com/TheJazMaster/Nibbs/assets/47794482/cc90a1e7-5377-4990-b1d9-919dfe460b3d)

**Requires [Kokoro](https://github.com/Shockah/Cobalt-Core-Mods/tree/master/Kokoro)**.

The mod includes a full 21-card, 6-artifact deck, animations and dialogue, as well as plenty of custom card art (thanks to the incredibly talented **Soggoru Waffle**).

Features compatibility with Duo Artifacts and More Difficulty Options.

Links to this [GitHub page](https://github.com/TheJazMaster/Nibbs) and the [modloader](https://github.com/Shockah/Nickel/releases/latest)'s.
